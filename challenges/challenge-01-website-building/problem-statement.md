# Challenge 01 – Website Building Challenge

**CODESTORM 2026 – November Edition**  
**Organized by GDG on Campus – RIT Hassan**

## 1. Problem Statement

In today's digital world, websites play an important role in connecting people, sharing information, providing services, and solving real-world problems.

Participants are challenged to design and develop a **professional, responsive, interactive, and user-friendly website** for a real-world purpose.

The website may represent a college, department, student club, organization, business, educational platform, or an innovative idea that provides value to users.

Participants must demonstrate their creativity, technical knowledge, problem-solving ability, and understanding of modern web development.

## 2. Objective

The main objective is to build a complete website that:

- Solves a real-world need or provides meaningful information.
- Offers a clean, attractive, and user-friendly interface.
- Works smoothly on mobile phones, tablets, and desktops.
- Includes useful and functional features.
- Demonstrates good coding practices.
- Uses the official logos provided by the organizers.
- Is deployed and accessible through a public website link.

## 3. Suggested Website Domains

Participants can select any suitable domain, including:

1. Education and E-Learning
2. College and Department Websites
3. Student Clubs and Communities
4. Business and E-Commerce
5. Healthcare and Wellness
6. Agriculture and Farmer Support
7. Environment and Sustainability
8. Event Management
9. Personal Portfolio
10. Social Impact and Community Services

These are suggestions. Participants may propose other innovative website ideas.

## 4. Mandatory Website Requirements

Every submitted website must include the following:

### A. Official Logos

The website must display all three official logos:

- Rajeev Institute of Technology (RIT) Logo
- Computer Science and Engineering Department Logo
- GDG on Campus – RIT Hassan Logo

**Important:** Use the official logo files provided by the organizers. Logos must be clearly visible and should not be distorted or unnecessarily modified.

### B. Required Sections

1. **Home:** Website title, introduction, navigation, and attractive landing section.
2. **About:** Purpose, background, objectives, vision, or mission.
3. **Main Content:** Information and services related to the selected website domain.
4. **Features:** At least three meaningful features.
5. **Contact:** Contact information, communication links, or a functional contact form.
6. **Footer:** Copyright information and relevant social or useful links.

## 5. Technical Requirements

- Responsive design for mobile, tablet, and desktop.
- Functional navigation and buttons.
- Clean and organized code.
- Proper use of images, icons, and other assets.
- Working internal and external links.
- Good loading performance.
- Basic accessibility and readable content.
- Compatibility with modern web browsers.
- Public deployment of the completed website.
- Public GitHub repository containing the source code.

## 6. Suggested Technologies

Participants may use any suitable technologies.

**Frontend:** HTML, CSS, JavaScript, React, Next.js, Vue, or Angular.

**Backend:** Node.js, Express.js, Python Flask, Django, or other suitable technologies.

**Database:** MySQL, PostgreSQL, MongoDB, Firebase, Supabase, or other suitable databases.

These technologies are suggestions, not restrictions.

## 7. Optional Advanced Features

Participants can improve their projects by implementing:

- User authentication and login.
- Admin dashboard.
- Database integration.
- Search and filtering.
- Event management.
- User profiles.
- API integration.
- Interactive animations and 3D elements.
- Email notifications.
- Dark and light themes.

These features are optional and may help demonstrate additional technical skills.

## 8. Expected Deliverables

Participants must prepare:

1. A completed and functional website.
2. A public GitHub repository containing the source code.
3. A publicly accessible deployed website URL.
4. A professional project README file.
5. A short project description explaining the purpose and features.

Additional screenshots, videos, or presentations may be requested by the organizers.

## 9. Evaluation

Projects will be evaluated based on:

- UI/UX Design and Visual Appeal.
- Functionality and User Experience.
- Technical Implementation.
- Creativity and Innovation.
- Responsive Design.
- Code Quality and Organization.
- Project Presentation.

Refer to [evaluation-criteria.md](evaluation-criteria.md) for the proposed marking distribution.

## 10. Important Instructions

- Original work is encouraged.
- Copying another participant's complete project is not allowed.
- Open-source tools, libraries, templates, and AI assistance may be used responsibly.
- Participants must understand and explain their submitted work.
- All mandatory requirements must be satisfied.
- Submission instructions and deadlines will be announced by the organizers.
