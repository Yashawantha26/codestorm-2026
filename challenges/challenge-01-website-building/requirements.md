# Challenge 01 – Website Building Challenge
## Official Website Requirements

**Event:** CODESTORM 2026 – November Edition  
**Organizer:** GDG on Campus – RIT Hassan

## 1. Introduction

Participants must develop a professional, responsive, interactive, and user-friendly website based on a real-world purpose or idea.

The website should demonstrate creativity, technical knowledge, practical implementation, and good user experience.

All participants must satisfy the mandatory requirements listed below.

## 2. Mandatory Logo Requirements

Every submitted website must display these three official logos:

1. Rajeev Institute of Technology (RIT) Logo.
2. Computer Science and Engineering Department Logo.
3. GDG on Campus – RIT Hassan Logo.

### Logo Guidelines

- Use the official logo files provided by the organizers.
- Display all three logos clearly.
- Maintain the original proportions and quality.
- Do not stretch, distort, or unnecessarily recolor the logos.
- Place logos in an appropriate section, such as the header or footer.

## 3. Mandatory Website Sections

### 3.1 Home Section

Must include:
- Website name and title.
- Short introduction.
- Navigation menu.
- Attractive landing section.
- Relevant images or visual elements.

### 3.2 About Section

Must include:
- Website introduction.
- Purpose of the project.
- Main objectives.
- Vision or mission, where relevant.

### 3.3 Main Content Section

Must provide meaningful information related to the selected domain.

Examples:
- Services and products.
- Educational content.
- Community information.
- Events and activities.
- Real-world solutions.

### 3.4 Features Section

- Include at least three meaningful features.
- Features must be relevant to the website's purpose.
- Interactive features should work as expected.

### 3.5 Contact Section

Include at least one suitable communication option:
- Contact information.
- Email link.
- Social media links.
- Contact form.

If a contact form is included, explain or implement how submitted information is handled.

### 3.6 Footer Section

Must include:
- Copyright information.
- Relevant social media links.
- Useful navigation links.
- Appropriate organization or project details.

## 4. Technical Requirements

| Requirement | Description |
|---|---|
| Responsive Design | Must work on mobile, tablet, and desktop. |
| Navigation | Menus and navigation links must work. |
| Functionality | Buttons and interactive elements must behave correctly. |
| Code Quality | Code should be clean and organized. |
| Performance | Avoid unnecessary loading delays. |
| Accessibility | Use readable text, suitable contrast, and meaningful labels. |
| Browser Support | Support modern web browsers. |
| Deployment | Website must be publicly accessible. |
| Source Code | Public GitHub repository is required. |

## 5. Technology Requirements

Participants may choose any suitable technology.

### Frontend
- HTML5
- CSS3
- JavaScript
- React
- Next.js
- Vue.js
- Angular

### Backend
- Node.js
- Express.js
- Python Flask
- Django
- Other suitable backend technologies.

### Database
- MySQL
- PostgreSQL
- MongoDB
- Firebase
- Supabase

**Note:** The technology stack is not restricted to this list.

## 6. Optional Advanced Features

Participants may implement additional features to improve their projects.

- User registration and login.
- Admin dashboard.
- Database connectivity.
- Search and filtering.
- Event management.
- User profiles.
- API integration.
- Interactive charts.
- 3D animations.
- Dark and light mode.
- Email notifications.
- File uploads.

These features are optional, not mandatory.

## 7. GitHub Repository Requirements

Every participant must maintain a public GitHub repository.

The repository should contain:

- Complete project source code.
- Organized folders and files.
- README.md file.
- Project description.
- Technology stack.
- Installation and setup instructions.
- Screenshots, where appropriate.

The repository link must be accessible to the evaluation team.

## 8. Deployment Requirements

The website must be deployed using a suitable hosting platform.

Suggested platforms:

- Vercel.
- Netlify.
- GitHub Pages.
- Cloudflare Pages.

### Deployment Checklist

- Website opens through a public URL.
- Main pages load correctly.
- Navigation works.
- Images and logos display correctly.
- No major broken links.
- Important features work as expected.

## 9. Content and Design Guidelines

- Use professional and readable typography.
- Maintain consistent colors and spacing.
- Avoid unnecessary animations.
- Use appropriate images and icons.
- Keep the content meaningful and relevant.
- Ensure the website is easy to navigate.
- Do not include misleading, offensive, or harmful content.

## 10. Responsible Use of AI and Open-Source Resources

- AI tools may be used responsibly.
- Open-source libraries and frameworks are permitted.
- Participants must understand the code they submit.
- Give appropriate credit to third-party resources.
- Follow the licenses of external assets and libraries.
- Do not present another person's complete project as original work.

## 11. Final Mandatory Checklist

Before submission, verify that:

- [ ] All three official logos are displayed.
- [ ] Home section is completed.
- [ ] About section is completed.
- [ ] Main content section is completed.
- [ ] At least three meaningful features are included.
- [ ] Contact section is available.
- [ ] Footer is completed.
- [ ] Website is responsive.
- [ ] Navigation and buttons work.
- [ ] GitHub repository is public.
- [ ] Website is deployed and publicly accessible.
- [ ] Project README is included.

All mandatory requirements are subject to verification by the organizers.
