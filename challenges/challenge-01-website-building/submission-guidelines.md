**Event:** CODESTORM 2026 – November Edition  
**Organizer:** GDG on Campus – RIT Hassan  
**College:** Rajeev Institute of Technology, Hassan  
**Department:** Computer Science and Engineering

## 1. Introduction

All participants must prepare and submit their completed website projects according to these guidelines.

A valid project submission must include:

1. Completed website.
2. Public GitHub repository.
3. Live deployed website URL.
4. Project description.
5. Required participant or team details.

The official submission method and deadline will be announced separately by the organizers.

Participants should keep the following information ready:

## 3. GitHub Repository Guidelines

Every participant or team must maintain a public GitHub repository.

### Repository Requirements

- Repository must be public.
- Include complete project source code.
- Organize files and folders properly.
- Add a professional `README.md` file.
- Include project screenshots, where appropriate.
- Mention the technologies used.
- Provide installation and setup instructions.
- Ensure that the evaluation team can access the repository.

### Suggested README Structure

Your project README should include:

1. Project title.
2. Project overview.
3. Problem or purpose.
4. Features.
5. Technologies used.
6. Installation instructions.
7. Screenshots.
8. Live website link.
9. Contributors.
10. Credits and acknowledgements.

## 4. Live Website Deployment

Participants must deploy their completed websites using a suitable hosting platform.

### Suggested Platforms

- Vercel
- Netlify
- GitHub Pages
- Cloudflare Pages

### Deployment Checklist

Before submitting, verify:

- Website opens through a public URL.
- Home page loads successfully.
- All required sections are available.
- Navigation links work.
- Images and official logos display correctly.
- Buttons and interactive features work.
- Website is responsive.
- No major errors or broken links are present.

- [ ] Project is ready for evaluation.

## 7. Submission Process

Follow these steps:

1. Complete your website.
2. Test all features and required sections.
3. Upload the source code to a public GitHub repository.
4. Deploy the website and verify the live URL.
5. Prepare your project description and participant details.
6. Submit the required information through the official project submission method announced by the organizers.
7. Keep your GitHub repository and deployed website accessible for evaluation.

**Important:** The event registration form and project submission process are separate unless the organizers officially announce otherwise. Registering for the event does not automatically submit your completed project.
